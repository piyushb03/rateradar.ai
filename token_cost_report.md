## 2. Architectural Decision & Trade-off Analysis

### Why Zero LLMs for Core Freight Calculations?
1. **Financial & Operational Accountability:** In freight pricing and billing reconciliation, calculations must be reproducible down to the decimal cent and verifiable against source invoices. A non-deterministic generative LLM can hallucinate numbers or introduce variance between identical requests.
2. **Zero Ingestion Latency & Zero Outage Risk:** Local execution requires no network hops, has zero downtime dependencies on third-party cloud outages, and requires no API key provisioning or ongoing API costs.
3. **Data Privacy & Security:** Sensitive freight contracts, carrier identities, and shipping volumes remain entirely inside the local execution environment without exposure to third-party model providers.
4. **Transparent Explainability:** Every justified verdict cites the exact source note ID (`N001`, `N002`, `N003`), exact date window, and comparison metrics, ensuring compliance with audit requirements.
